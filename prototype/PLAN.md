# Browser nominal control feasibility probe

This isolated branch is a design experiment for expanded #542, not a production implementation or native absence claim. Test whether a small actual TypeScript protocol owner can expose nominal domains to existing classic JavaScript through strict checkJs, with no new bundler or wrapper/identity cache. Compare closed enum tokens; translate unknown wire strings through explicit Maps at one boundary. Preserve transport bytes and reject unsupported values.

The toy enums are deliberately local to this feasibility test. Production wire vocabularies must be generated from the actual canonical Python owners, never maintained as a parallel spelling catalog. Browser UI state has its own cohesive owner. Existing report JavaScript needs precise actual DTOs and explicit decode/serialize ports; no any, ignored compiler errors or broad casts may stand in for those definitions.

Probe positive runtime behavior, exact JSON spelling, unknown rejection, cross-domain compiler rejection and raw protocol-string compiler rejection with pinned TypeScript5.9.3. A real browser integration must additionally retain cloning boundaries, route/filter behavior and rendering performance, with independently authored native API intent and honest JavaScript detector limits. No browser production file changes in this experiment.
