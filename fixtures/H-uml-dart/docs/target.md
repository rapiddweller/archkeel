# Dart checkout Target

This independent Target describes a small checkout package. The composition root owns `lib/main.dart`, requires presentation, ordering and adapters, calls the controller entry point, and creates the checkout service and in-memory repository. Presentation maps requests to ordering; ordering owns application, ports and domain; adapters implement ports and format receipts. A repository binding records the concrete constructor assignment. `inside` expresses component ownership. UML `parent_id` expresses module and lexical ownership.

The package and scan namespace are both `commerce`. Dart module identities use the path below `lib` with `.dart` removed: `lib/ordering/domain/orders/order.dart` is `commerce.ordering.domain.orders.order`. No source facts are used to create this Target.

Classifier/member scopes are closed per module where the declared inventory is deliberate. Module, import and call inventories remain open: the current Dart profile records directives only, so it cannot certify those inventories or turn unsupported members into PASS or absence FAIL. `PercentageDiscount` extends `DiscountBase`, realizes `DiscountPolicy`, and delegates clamping to `super.clampDiscount`; these are static Target relations, not runtime proof. `CheckoutRequest` is declared once as the presentation data class. The table describes the intended acceptance outcomes; the existing flat source is not an implementation of this Target. Source implementation and report acceptance are later tasks.
