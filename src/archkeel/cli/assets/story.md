# Story guidance

Write a short explanation for each step. Use the snapshot to find the functions and calls.
Treat unlinked calls, dynamic dispatch and process boundaries as unverified.
Do not describe an author claim as a proven call.

See `example.story.json` in this directory for the view spec 1.2.0 shape.
Replace its nodes before you copy it to `.archkeel/stories/`. Studio rebinds the snapshot on read.
