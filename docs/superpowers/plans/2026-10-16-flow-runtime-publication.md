## Accepted design

The current typed Scene report exceeds the unchanged2MB/400KB budgets. An auxiliary standard-printer proof already preserved all eight programs' semantic ASTs and passed18 Chromium checks; this increment publishes only the single existing flow.js program. Its measured31,165-byte formatting saving is sufficient. Do not print, replace or add generated versions of the other seven assets.

flow.js remains the only authored program. A small strictly checked Python publisher invokes locked Terser with explicit compress:false, mangle:false and comments:false options. The generated flow.runtime.js carries its source SHA-256 and publisher provenance. HTML selects that derivative at exactly the former flow.js load site. No bundle, new load boundary, runtime Node dependency, source policy exclusion or HRC allowance is introduced. Current own observation is Python; actual native JS probes explicitly observe the authored source. The generated file is verified derivation, not another architecture authority.

Source and derivative both ship through the existing asset packaging rule. The sdist includes their bytes and rebuilds offline without Node; build tooling stays outside the sdist. Tradeoff: approximately155,225 generated bytes plus a short provenance header, a small publisher and locked development-tool metadata. This is an explicit packaging/source cost, not hand-authored architecture code.
