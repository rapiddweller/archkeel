# AD-195 Overviews separate boundaries from file intent

Show declared components as root boundaries, with imports or permissions.
Files and namespace groups are not peer components. Drill into recorded or
independently declared code; file inventories remain intent in Details, not
inferred entities or owners.

Keep unassigned code reachable with unchanged identities, findings and UNKNOWN.
Projects without components retain a code overview. Layout bands declare no
architecture layers. Prefer readable scale and panning; an overview cannot
certify crossing-free routes.
