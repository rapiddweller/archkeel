# AD-104 A contract the compared revision lacks is introduced

An absent reference contract is one widening requiring a path-bound amendment. Only a missing blob
proves absence; invalid revisions, non-files and malformed contracts exit two. A moved contract is
introduction, not an inferred rename.

Compare surviving prior debt, but do not duplicate jointly absent policy. Approval can cover
reintroduction at the same path, never another path. Without a reference contract, no reference call
scan is possible. Proof:
[test_against_introduction.py](../../../tests/test_against_introduction.py).
