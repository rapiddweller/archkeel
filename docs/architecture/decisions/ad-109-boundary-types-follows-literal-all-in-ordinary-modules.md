# AD-109 `boundary_types` follows literal exports from ordinary modules

Follow ordinary-module facade imports through stable literal `__all__`, unique
bindings and a proven terminal definition. Every hop needs proof; candidates never
become origins. Unproved routes retain UNKNOWN without invented signature positions.

Only the type's owner can publish its exact definition. Unrelated uncertain routes
cannot suppress known violations; public exports cannot exempt broad fields.
Dynamic exports and runtime mutation remain unproved.
