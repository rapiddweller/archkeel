# AD-178 Target navigation projects the standard graph

Project Target navigation from Core's authenticated `ArchitectureGraph`, rather
than reconstruct intent from declaration payloads. Components, parents, layouts
and inventories need one semantic source.

`render.target` owns navigation projection; HTML embeds evidence, and the browser
owns geometry and interaction. Core retains authentication, comparison and verdicts.
File aliases assert no class, call, existence or permission. Render intent is authored
from agreed responsibilities, independently of Source.
