# AD-34 A declared inside is recorded, so the report draws it without reading a second contract

Record declared inner components under their parent, without promoting them to global owners.
Declarations support navigation; conformance requires evaluated evidence. Missing evidence is
UNKNOWN, and unruled edges remain observed.

[AD-110](ad-110-inside-rules-use-the-shared-evaluator.md) supplies shared evaluation;
[AD-111](ad-111-recursive-inside-contract-tree.md) supplies recursively mounted levels. One
canonical observation carries the result.
