# AD-116 Diagram filtering is an explicit choice

Make filtering explicit. Open at 100% zoom with all groups and threshold zero;
preserve user choices during navigation. Focus includes every direct neighbor
and violated edge; counters disclose filtering.

Use bounded native scrolling. Fit is explicit; Arrange changes positions without
filters or zoom. Navigation resets stale scroll offsets, and folder state belongs
to its breadcrumb. Inventory equality cannot prove visual usability.
