# AD-742 The decision index is generated from the record files

**Status.** Accepted. Part of #880 (lead request of 2026-11-17, DX). Visible change: `docs/architecture/decisions/README.md` holds no table.

**Reason.** The hand-edited index was the most frequent merge conflict: every pull request that added a record edited the top of the same table, so authors merged main again and again. The index also drifted from the files: it held 542 rows for 539 files, one row named a file that no longer exists (AD-558), and the old test keyed rows by number, so two rows with one number passed.

**Decision.**
1. The list is generated by `tools/decision_index.py` from the files `ad-<n>-*.md`: number from the file name, title from the first heading, a link, newest first. `--write PATH` writes it, `make decision-index` writes `test-artifacts/decision-index.md`.
2. `--check` (and `tests/test_repository_hygiene.py`) fails on a record without heading, a bad file name, and a number that two records share.
3. The README holds the explanation only. The hand-written list of 2026-11-17 is kept, unchanged, in `INDEX.md` (frozen: nothing deleted, including the dead AD-558 row).
4. A pull request that adds a record adds one file and edits no shared line.

**Rejected.** `.gitattributes` `merge=union`: GitHub merges with its own engine and ignores it, so the gate would still see a conflict. A committed generated list: the same shared lines again.

**Tests.** `tests/test_decision_index.py`.
