# AD-162 Physical intent does not invent UML

Retain module inventories and layout permissions as physical intent.
Absent and empty inventories differ. A file responsibility declares no classes,
methods or calls; an allowed package need not exist. Layout rules are not edges.

Canonical Target references declaration IDs without copying contents.
Core authenticates contents and owners; unsafe paths, duplicate inventories and
source graphs carrying intent are invalid. Shared types retain compatible exports.
UML comparison adds no second physical verdict.
