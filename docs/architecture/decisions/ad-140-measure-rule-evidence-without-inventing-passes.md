# AD-140: Measure rule evidence without inventing passes

Measure rule yield from actual producer verdicts and reconciled population receipts.
Absence of violations alone does not prove PASS. Keep allowances, violations and UNKNOWN separate;
unreconciled or unsupported pass counts remain null. Population reconciliation does
not close uncertain scope. Permission declarations remain declarations, and type,
import and scope units cannot be summed.

Keep timings outside canonical IR. Publish independent replay runtime only when
findings match; unavailable proof stays unavailable. Profiling overhead cannot invent
exclusive time. The tool is Python-only and adds no metric gate.
