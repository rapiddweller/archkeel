# AD-130: Review starts with findings and snapshot evidence

Open reports with verdicts, findings and limits before the explorer.
Finding links reveal hidden records and ancestors. Show cited evidence, rationale,
authorship and snapshot binding so reviewers can assess the result.

Escape repository content; reuse native details and copy fields. Unavailable
comparison never means no changes. Presentation cannot change JSON, evaluators or
verdicts. Human review improvements need separate evidence.
