# Current Delta dimensions

Profiles owns the eight current comparison dimensions because it already owns their applicability. Model imports measurements, which imports profiles: placing the canonical domain in model would introduce a cycle. Model explicitly reexports the identical enum for existing semantic-model consumers. This adds no module or framework.

Known producer and fixed expectation decisions use that class. Public SemanticChange.dimension, DimensionDelta.name and coverage dimension lists remain extensible strings; fixed governance rejects unsupported dimensions at its actual ingress. Public dimension tuples remain plain wire strings. Source-section and scalar vocabularies keep their separate meanings.

The two evidence checks use Facts.EvidenceClass. Existing evidence error messages and validation priority remain unchanged. Exact complete function guards protect only genuinely migrated ports; _logical_payload still reads the separately tracked boundary_type_position producer tag, and parse_expectation still has a separately tracked version decision. No whole-model, whole-codec or whole-parser absence is claimed.

Authored Target protects nominal ownership, primitive ingress, applicability, algorithm input/return, selected expectation dimension and open public semantic dimension. Native mutations keep this intent fixed. Legacy/future wire bytes, malformed evidence, error order, profile applicability and actual producer fingerprints are separate runtime controls.
