# Core Command and result controls

Part of #542. Command belongs to ir.model beside RunResult, and cli.arguments preserves an identical explicit reexport. Its six runtime tags do not expand the published four-command JSON schema. ContractCommand.command remains arbitrary shell-command data. Observation completion is the PASS/UNKNOWN Literal subset of canonical AssessmentStatus; expectation outcome is a separate PASS/FAIL/UNKNOWN/n/a domain. Binary Verdict fields and Amendment, Delta and Measurement states are outside this stage.

The independent Target reuses existing model and RunResult identities. CLI retains actual whole-package raw-dispatch protection. A source-backed native fixture additionally protects only the selected Command/ExpectationOutcome/RunResult declarations; this is explicitly not a whole-model string-freedom claim. The remaining model/summary controls stay pending under #542.
