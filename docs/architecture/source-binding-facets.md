# Source binding facets

Facts owns the three written call-result target forms (name, attribute, subscript) and the three source assignment categories (type alias, static constant, dynamic binding). Lexical binding ownership and graph entity kinds remain separate domains.

Python, Dart and TypeScript publish the shared result-target tags at their actual call-record writers. Python assignment records, Dart category metadata and the conservative unproven-binding view publish the shared assignment tags. Optional readers normalize known JSON values once; unrelated and future record metadata remain open.

Graph projection propagates the nominal result target through reconciliation and construction. Source categories map to existing graph entities without widening the graph or classifier contract grammar. Replay uses the existing ResolutionInput/ResolutionRole owner and retains the exact path/digest/role wire order.

The authored reader and producer signatures and complete reader/reconciliation function guards are native contract checks. JSON keys, paths and symbol names remain data.
