# Source name visibility

Python's source-name tags are exactly `private` and `public_name`. They describe underscore spelling, including a private spelling for dunder names. The separate language API visibility detail uses `public`/`private` and keeps its own meaning.

Facts owns `SourceNameVisibility` and an optional reader. Actual symbol and import-origin writers emit these members; onboarding, interface measurement and uncertain-import evaluation decode historical wire tags once and compare nominal members. Unknown, foreign and non-string values remain unclassified. JSON spelling and interface verdicts remain compatible.

The existing Facts component owns the enum and reader. Authored API input/return intent, unchanged-contract mutation controls, exact function string-comparison guards, real producer identity checks and canonical report parity validate the boundary.
